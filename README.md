## Qué hace

Landing de una sola página para **Grupo Leiva**, con navegación por anclas entre todas sus secciones. Está generada de forma **estática en build** (prerender), así que no necesita servidor: se sirve tal cual desde cualquier hosting estático.

## Funcionalidades

- Página única con navegación por secciones (anclas).
- Secciones: Inicio, Nosotros, Misión, Visión, Promesa, Valores, Paquetes y Contáctanos.
- Prerender estático en build (buen SEO sin servidor).
- Estilos con SCSS anidado.

## Uso local

```bash
npm install
ng serve      # http://localhost:4200
```

Build de producción (estático, salida en `dist/grupo-leiva/browser`):

```bash
npm run build
```
